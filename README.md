## Simulations from the paper

Running the following scripts will produce the results for all the simulations in the paper. The results are stored in the respective directories as shown below:

| Script | Description | Results Location |
|--------|-------------|------------------|
| [run-100g_log.sh](https://github.com/ants-xjtu/Occamy-Simulation/blob/eurosys25-artifacts/ns-3/examples/Occamy/run-100g_log.sh) | Generates log simulation results | `ns-3/examples/100g_motivation` <br> `ns-3/examples/log_motivation_log` |
| [run-100g_test.sh](https://github.com/ants-xjtu/Occamy-Simulation/blob/eurosys25-artifacts/ns-3/examples/Occamy/run-100g_test.sh) | Generates test simulation results | `ns-3/examples/100g_test` |
| [run-100g_alltoall.sh](https://github.com/ants-xjtu/Occamy-Simulation/blob/eurosys25-artifacts/ns-3/examples/Occamy/run-100g_alltoall.sh) | Generates all-to-all simulation results | `ns-3/examples/100g_alltoall` |
| [run-100g_allreduce.sh](https://github.com/ants-xjtu/Occamy-Simulation/blob/eurosys25-artifacts/ns-3/examples/Occamy/run-100g_allreduce.sh) | Generates all-reduce simulation results | `ns-3/examples/100g_allreduce` |
| [run-100g_queryload.sh](https://github.com/ants-xjtu/Occamy-Simulation/blob/eurosys25-artifacts/ns-3/examples/Occamy/run-100g_queryload.sh) | Generates query load simulation results | `ns-3/examples/100g_queryload` |
